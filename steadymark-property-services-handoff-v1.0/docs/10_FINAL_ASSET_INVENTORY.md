## Provenance rule

Use internal provenance states:

- REAL
- REFERENCE-DERIVED
- SYNTHETIC REPRESENTATIVE
- DESIGN REFERENCE
- DOCUMENTARY PROJECT (future)

Synthetic representative media illustrates capability and service context; it cannot be converted into a fake completed-project claim.

## Replacement hierarchy

Highest long-term replacement value:

1. Robert reference-derived public imagery
2. Service-Line representative imagery as real SteadyMark work accumulates
3. Generic homepage/property imagery
4. Detail/task imagery

Identity masters do not need replacement merely for freshness.

## Non-authoritative content
